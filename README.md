# pair-wise-yf-50 灾后需求评估与任务分派离线前端

源提示词摘要：评估员在弱网环境离线记录家庭需求、特殊照护和现场说明，团队负责人合并重复记录、分派复核任务并追踪进展；多人修改同一记录时提供字段级冲突展示，不静默覆盖。

## 核心模型：可恢复的本地修订账（revision ledger + outbox）

家庭需求记录、待同步队列、任务分派统一接入同一条**本地修订账**：

- 每次保存登记一条不可变修订：`deviceId / deviceName`（设备标识）、`baseVersion + 各字段 baseValues`（基础版本/基线值）、`changedFields`（只含改过的字段）与单调序号 `seq`。
- 离线期间持续向账本追加修订（不覆盖旧修订）；回网后整批按序号提交。
- **字段级三方合并**（base / 本机 / 远端）：不同字段自动合并；同一字段被两台设备基于同一旧值各自修改 → 登记字段冲突，保留双方数值，后写不覆盖前写。
- **幂等提交**：每条修订有全局唯一 `revisionId`，服务端只入账一次；“提交成功但响应丢失”后重试只重放，不会多出一份。
- **失败可恢复**：提交中的修订在崩溃/掉电/杀进程后，启动时自动恢复为“待处理”，可原样接着提交。
- **冲突阻断**：字段冲突未人工处理前，相关家庭的任务推进、分派、重复合并全部锁定。
- **合并不留未结任务**：重复记录合并时，被合并家庭的未结任务必须全部迁移到保留家庭，被合并方保留墓碑。
- **版本回退**：已完成记录可回退到上一确认版本，回退本身生成补偿修订并同步，闭环任务相应退回进行中。

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `utils/domain.ts` | 领域模型：家庭/任务/修订/冲突类型、字段清单、快照、JSON 安全克隆 |
| `utils/server.ts` | 负责人合并端（模拟服务端）：revisionId 幂等账本、字段级三方合并、合并迁移任务、故障模式（响应丢失/503）、对端设备直改 |
| `stores/assessment.ts` | 设备标识、本地修订账与 outbox、字段修订登记、对账（reconcile）、冲突处理、合并、任务门禁、失败恢复、版本回退、localStorage 持久化 |
| `pages/index.vue` | 需求记录/字段修订、重复合并、任务分派（含冲突锁定）、同步队列与弱网演练、字段级冲突处理 |
| `scripts/verify-ledger.mjs` | 服务端账本语义验证（幂等/三方冲突/字段合并/合并迁移） |
| `scripts/verify-store.mjs` | 客户端全链路验证（失败恢复、冲突门禁、合并迁移、回退、重启恢复） |

## 界面内弱网演练

「同步队列」面板内置三步复现两台设备同改一字段：

1. **远端B改地址**：负责人平板B 在服务端直接修改；
2. **本机离线改同一地址**：本设备追加一条字段修订进入待处理队列；
3. **回网提交**：服务端三方合并发现同字段分歧，生成字段冲突，任务随即锁定，人工“采用本机/远端”后生成解决修订再次入账。

链路状态可切换「正常 / 响应丢失 / 服务端503」，用于验证幂等重放与失败恢复；右侧“负责人合并账本”展示按 `revisionId` 去重的入账流水。
